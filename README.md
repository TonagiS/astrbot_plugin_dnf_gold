# DNF 金币行情

发送 /查询金价，按跨区（跨一~跨八）返回 uu898 上 DNF 游戏币的实时最优比例（1 元 = X 万金币）。dd373 已被滑块验证拦死，故换源。

> 从个人自用环境里抽出来开源的一份，发布前做过脱敏：所有 QQ 号、群号、本机绝对路径、token 都换成了空值或占位符。
> 装完记得按下面的说明填自己的。

## 安装

放到 AstrBot 的插件目录（`data/plugins/`）下，重载插件或重启 AstrBot 即可。AstrBot 4.24.0+，平台适配器 `aiocqhttp`。

## 配置

`groups` 留空表示所有群都能查；抓的是 uu898 的公开挂单页，站点改版可能失效。

## 说明

- 依赖 AstrBot 自带的 `astrbot.api`，不需要额外 pip 包（站点抓取用标准库，无第三方依赖）。
- 日志写在自己插件目录的 `data/` 下，不会污染别处。

# astrbot_plugin_dnf_gold · DNF 金币行情

`/查询金价`（别名 `/金价`、`/dnf金价`）→ 按跨区返回 DNF 游戏币的实时比例。

## 输出样子

```
DNF 金币行情 · uu898 · 11-19 23:30
跨一: 100.10万/元
跨二: 92.33万/元
...
跨八: 91.00万/元
```

- 「万/元」= 1 元能换多少万金币，**越大越划算**
- 每个跨区取该跨区所有在售挂单（28 个 DNF 大区各首页 20 条）里的最高比例

## 数据来源

`https://www.uu898.com/tgWeb/newTradeTG.aspx?gm=95&...&area=<大区id>`（DNF → 游戏币）。
页面是服务端渲染的 UTF-8 HTML（可能 gzip），插件用标准库（urllib + gzip + re）解析，
**不依赖第三方包**。取数逻辑在 `gold_source.py`。

每条挂单自带「区服」（如「广东区 / 广州1／2区」）和「1元=X万金」，
按下面的 DNF 跨区大区表映射回 跨一~跨八，一个跨区取 max：

| 跨区 | 包含大区/区服 |
|---|---|
| 跨一 | 广东1-13、广州1/2、广西1-5 |
| 跨二 | 湖北1-8、湖南1-7 |
| 跨三A | 四川1-6、西北1-3、新疆1 |
| 跨三B | 西南1-3、陕西1-3、重庆1/2、云南1、贵州1、云贵1 |
| 跨四 | 江苏5-8、浙江4-7、上海4/5、江西3、安徽3、福建3/4 |
| 跨五 | 上海1-3、浙江1-3、江西1/2、江苏1-4、福建1/2、安徽1/2 |
| 跨六 | 北京1/2/4、东北1/2/3/7、河北1、河南1/2、黑龙江1、华北1、吉林1/2、辽宁1、山东1/2/7、山西1 |
| 跨七 | 辽宁2/3、河南3-7、河北2-5、东北4-6 |
| 跨八 | 黑龙江2/3、华北4、山东3-6、山西2、北京3、天津、内蒙古 |

表里没有的新服会自动跳过；某个跨区一条挂单都没抓到就显示「无数据」。

### 为什么从 dd373 换过来

dd373（`www.dd373.com/s-rbg22w-...html`）从 2026-11-19 起对所有非浏览器客户端返回
阿里云 ESA 的「滑动验证」滑块页（`X-Tengine-Error: denied by http_security_level_rule`），
无头 Edge 也被弹滑块，urllib + 固定 UA 拿到的只有 11 KB 的挑战页，解析出来 0 条挂单。
uu898 目前没有这层验证，28 个大区页并发抓完约 20 秒。

## 配置项

| 键 | 说明 | 默认 |
|---|---|---|
| `groups` | 生效群号，留空=所有群 | `123456789`、`987654321` |
| `cache_seconds` | 数据缓存秒数 | 180 |
| `cooldown_seconds` | 同群最小查询间隔 | 120 |

## 已知限制

- 只读各大区首页 20 条（够看最优，不代表全站成交价）。
- 一轮刷新 28 个请求、约 20 秒；插件加载时后台预热一次，缓存 180 秒。
- uu898 风控/维护时抓取失败，插件会回一句「抓取失败」，不会静默吞消息。
